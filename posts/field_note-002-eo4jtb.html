AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉 현장 분석

## 관찰 기록

### 현장 단서

#### AWS 프리티어 계정 사용 사례
AWS 프리티어 계정으로 운영하다 한 달 만에 청구된 500만원 트래픽 패턴을 보고, 이를 해결하기 위해 Lightsail 인스턴스의 CPU 크레딧 관리를 깊게 알아봤다.

#### 예측 가능한 현상
AWS Lightsail에서 CPU 크레딧이 소진되는 경우를 고려하지 않고 서비스를 운영하다 보면, 3분 전에 커널 패닉 현상이 발생하는 AMI 조합을 발견했다. 이를 통해 실패 원인과 대응 방법을 찾는 데 도움이 되었다.

### 판단 메모

#### 금지 지식 절대 규칙
AWS 서비스 개요, 비용 절감 일반 팁, 서버리스 아키텍처 장단점 모두 금지 지식으로 설정했다. 대신 AWS 프리티어 계정 운영 실패 사례를 깊게 조사해 내부 원인을 찾았다.

#### 관점 강제
DevOps 엔지니어의 시점에서, 클라우드 비용 절감에 대한 일반적인 지침을 무시하고 AWS 프리티어 계정 운영 실패 사례를 중심으로 서사를 전개했다. 이를 통해 사용자들이 AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉 현상을 경험하는 과정과 그 원인을 이해하도록 했다.

## 검색 의도 대응
#### 구체적 질문
- 특정 AMI 조합이 CPU 크레딧 소진으로 인해 커널 패닉이 발생할 때, 이를 방지하기 위한 최대한의 조건은 무엇일까요?
- AWS Lightsail 인스턴스에서 CPU 크레딧 소진 현상에 대한 예방 수칙을 정리하고, 이 기준들이 일반적인 관행인지 아닌지를 판단하세요.

#### 실패 원인
- 특정 AMI 조합이 CPU 크레딧 소진으로 커널 패닉 발생.
- 3분 전 경고 없이 커널 패닉 현상 발생.

#### 비교 기준
- AWS 프리티어 계정 운영에서의 일반적인 비용 관행 vs Lightsail 인스턴스 운영에 대한 특별 조치 필요성
- 동일한 AMI 조합으로서, 다른 클라우드 서비스와의 비교 (Google Cloud, Azure)
